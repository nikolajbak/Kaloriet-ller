# Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ny navigation (bundbjælke med kamera), nye skærme (I dag, Udvikling, Indstillinger) og et fælles fundament, kontrolleret af en automatisk UI-kontrol.

**Architecture:** Vanilla JS i `index.html` (strengbyggede `tegn*()`), CSS flyttes til `style.css`. Fem faser, hver merget til `main` som en hel app. UI-kontrollen skrives først og udvides i hver fase (test før kode).

**Tech Stack:** Vanilla JS/CSS, service worker, Playwright 1.63 (forinstalleret, `require('playwright')`), `node:assert`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-11-redesign-design.md`

## Global Constraints

- Ingen eksterne JS-biblioteker i klienten; ingen nye npm-afhængigheder i repoet (CI installerer kun `playwright@1.63.0`).
- `APP_BUILD` (`index.html:557`) +1 pr. fase; `style.css` linkes `style.css?v=<APP_BUILD>`.
- Brugervendt tekst dansk, uformel, du-form; funktionsnavne på dansk.
- Tonegrænsen (aldrig krop, vægt, figur, udseende) og al AI-logik er urørt.
- Paletten (`:root`-variablerne, lys og mørk) uændret; nye tokens: afstand 4/8/12/16/24/32, radius 8/12/16/999, typografi 12/13/15/17/22 + 64 Georgia.
- Trykflader ≥ 44 × 44 px; kontrast ≥ 4,5:1 (≥ 3:1 for stor tekst); `prefers-reduced-motion` slår animationer fra.
- Pr. fase: UI-kontrol grøn lokalt (inkl. visuel) og i CI → PR merges af Claude til `main` → branch genstartes fra `main`.

## Review Focus

- Gemte data fra før redesignet: `S.skaerm` kan stå som `vaegt`/`historik`/`trends` (fx fra en åben fane ved genindlæsning) → skal vises som `udvikling`. Test i Task 3.
- Midnat mens en tidligere dag vises: `S.iDag` skifter (`index.html:6454`); `S.visDag` må ikke pege på »i morgen« og › skal deaktiveres korrekt. Test i Task 3.
- Kameraknappen på en tidligere dag med `S.autoreg` (live-kamera) → måltidet skal gemmes på den viste dag, ikke i dag. Test i Task 3 (asserter `maalDag()` når kameraet startes; kamera stubbes).
- Autogem midt i indtastning af mål (fx »2« på vej til »2200«) → I dag må ikke opdateres før `change`. Test i Task 6.
- Gammel service worker med `kaloriedagbog-skal-3` serverer gammel CSS → ny `?v=` skal hente ny `style.css`. Test i Task 1 (`sw.js` matcher `style.css` med søgestreng).
